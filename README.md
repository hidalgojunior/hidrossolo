# Hidrossolo — Índice de Versões

Este repositório está organizado por **versões, em branches separadas**.

> O branch `main` contém apenas este índice. **Nenhum código-fonte fica aqui.**

## Versões disponíveis

| Versão | Branch | Descrição | Situação |
|:------:|--------|-----------|:--------:|
| **1.0** | [`versao-1.0`](https://github.com/hidalgojunior/hidrossolo/tree/versao-1.0) | Versão antiga, baseada em **instalador** (`install/*.php`, `config.php`). | Arquivada |
| **2.0** | [`versao-2.0`](https://github.com/hidalgojunior/hidrossolo/tree/versao-2.0) | Versão atual: **PHP 8.3 puro** com MVC próprio, painel administrativo, CMS, gestão de frota, financeiro e PWA. | **Atual** |

## Como obter uma versão

```bash
git clone https://github.com/hidalgojunior/hidrossolo.git
cd hidrossolo

git checkout versao-2.0   # versão atual
# ou
git checkout versao-1.0   # versão antiga
```
